# 0003. Employee journey and admin backend

**Date**: 2026-09-18
**Status**: In Progress

## Summary

Two things land together, because the second is meaningless without the first:

1. **Real backends for the six admin screens** already built on sample data: Hotels, Departments, Manage Employees, Lessons & Content, Messages & Reminders, Reports & Export. Every number reads the database, every button does its job, every write is validated, authorized, audited and tested.
2. **The employee area**, built pixel-exact from the 28 mockups in `desginphotos/employ/`: the lesson runner (Situation → Vocabulary → Expressions → Listen & Repeat → Dialogue → Video → Practice (7 activity types) → AI Role-play (4 screens) → Lesson Complete) and the Pre-test (intro + 8 question types), plus the un-mocked support pages (My Lessons, My Phrasebook, My Progress, Messages, First login, Certificate) built from the design system.

This spec is the **contract** between the parallel build lanes. Names below (tables, columns, enums, routes, component files, JSON payload shapes, seed slugs, asset file names) are fixed; a lane that needs a different name changes this file first.

Spec 0002 (hotels) stays authoritative for the Hotels screen; this spec only schedules its build.

## Part A. Ground rules for every lane

1. **AGENTS.md §0 is law.** Mockup first, tokens only, locked chrome untouched (extend through props/slots only). Measure, never eyeball.
2. **Layering (scope ground rule, spec 0002 AC-20):** FormRequest validates → Service does the write → model methods read → a Resource/array-shaper shapes props → Policy + middleware guard. Controllers write no queries. Every mutation writes an `AuditLog` row via `AuditLog::record()`.
3. **Portability:** every migration runs on SQLite and MySQL 8.4. `string` + enum cast, never `$table->enum()`, never `->after()`, no `->change()` on unique columns (edit the users create migration directly instead).
4. **Laravel 13 model style:** `#[Fillable([...])]`, `#[Hidden([...])]`, `casts()` method, `@property` PHPDoc, generics on relations (`BelongsTo<Hotel, $this>`). PHPStan level 7 must pass.
5. **Frontend style:** `<script setup lang="ts">`, `type Props`, `cn()`, `@lucide/vue`, Wayfinder routes only (never a literal URL), `<Form v-bind="X.form()">` or `useForm` from Wayfinder URLs, `Inertia::flash('toast', …)` for confirmations. `npm run check` and `npm run types:check` must pass.
6. **Tests:** class-based PHPUnit under `tests/Feature/<Area>/`, `RefreshDatabase`, `test_snake_case`. Every scoped resource ships the cross-tenant 403 test.
7. **Shared files that several lanes touch** (`routes/admin.php`, `routes/learn.php`, `resources/js/app.ts`, `resources/js/types/index.ts`, `config/guesvia.php`, `config/services.php`, `HandleInertiaRequests`, `AppSidebar.vue`) are written once by the lane named as owner below. Other lanes append only in the marked slot and never reformat the file.
8. **New colour tokens:** sample the mockup, add `--color-<name>` (never a Tailwind palette name such as rose/pink/orange/teal/sky) to `@theme` in `resources/css/app.css` with a comment naming the mockup file, and list it in the lane report.
9. **Images:** the client has not supplied lesson photos. Seed images are **crops of the client's own mockups** (`desginphotos/employ/*.jpg`) produced by Part F, stored under `public/content/seed/`, and referenced from `media_assets` rows so the CMS can replace them (MED-02). No stock photos, no generated art, no emoji.
10. **Audio:** never synthesised at play time (CTRL-05, TTS-02). Every playable text resolves to an `audio_clips` row; the seeder generates clips through the fake TTS provider so the buttons work locally.
